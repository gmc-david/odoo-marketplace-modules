==================================
Website Search Redirect to Shop
==================================

Redirects Odoo's default website search results to your shop page. Customers
see product cards with images and prices in a familiar grid layout instead of
the generic plain-text search results list.

**Table of contents**

.. contents::
   :local:

Features
========

* **Automatic Redirect**: Website search bar results go to /shop instead of /website/search
* **Product Card Display**: Customers see the same rich product grid they see when browsing the shop
* **Zero Configuration**: Install the module and it works immediately — no settings to configure
* **Lightweight**: No database changes, no new fields, no models — just a controller and a small JS file
* **Theme Compatible**: Works with all standard Odoo themes
* **SEO Friendly**: Search terms are preserved in the URL for analytics tracking

Installation
============

1. Download the module from the Odoo Apps Store
2. Go to Apps menu in your Odoo instance
3. Click "Update Apps List"
4. Search for "Website Search Redirect to Shop"
5. Click "Install"

Configuration
=============

None required. The module works immediately after installation.

Usage
=====

After installation, any search performed via the website search bar will
redirect to the shop page with the search term applied. Customers will see:

* Product images and names in a grid layout
* Prices (including any pricelist-based pricing)
* Standard shop filtering and sorting options
* Add to cart functionality directly from search results

The default Odoo search results page (plain text list) is bypassed entirely.
