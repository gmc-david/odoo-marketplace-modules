How it works

  1. Configure quantity-based pricing rules in Sales > Configuration > Pricelists (at least 2 tiers per product).
  2. Link the pricelist to your website via Website > Configuration > eCommerce.
  3. Install this module — price ranges appear automatically on shop listings and product pages.
  4. Products with only a single price tier (or identical min/max) continue showing their standard price.

FAQ

What if a product only has one price tier?

It shows the normal single price. The range only appears when there are at least two different price points.

Does it work with product variants?

Yes. Variant-specific pricing takes priority. If no variant pricing exists, it uses the template-level rules.

Will it affect my shop page performance?

The module uses efficient database queries to fetch min/max prices for all visible products in a single call. Impact is minimal.

Can I disable it for specific products?

The range only appears when tiered pricing exists. Simply remove the pricelist rules for products where you don’t want ranges shown.

How does it change the price filter?

The standard shop price filter only considers the product’s list price. This module extends it to also search pricelist prices, so products with lower bulk prices appear when customers filter for lower price ranges.

Is it compatible with other TGM modules?

Yes. It works alongside the Pricing Table and Encouraging Price modules. Each adds a different layer to the volume-discount experience.
