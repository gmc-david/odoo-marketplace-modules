❓ Frequently Asked Questions

Does this work with product variants?

Yes! The module intelligently handles both product templates and individual variants. When a customer selects a variant, the pricing table updates to show that variant's specific pricing.

Can I customize the styling?

Absolutely. The module includes clean CSS that you can easily customize to match your brand. The styles are in a separate CSS file for easy modification, and it automatically adapts to your website's theme colors.

Will this slow down my website?

No. The module is lightweight and only loads when needed. It uses efficient JavaScript and doesn't add any noticeable load time to your pages.

What if I don't have pricelists configured?

The pricing table simply won't appear. There's no error - it gracefully handles products without quantity-based pricing.

Does it work with multiple currencies?

Yes! The module automatically displays prices in the customer's selected currency with proper symbol positioning (before or after the amount).
