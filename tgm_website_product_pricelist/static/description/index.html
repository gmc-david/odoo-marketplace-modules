How it works

  1. Configure quantity-based rules in Sales → Configuration → Pricelists.
  2. The module detects applicable rules for the product or variant.
  3. A pricing table appears automatically on the product page.
  4. Changing variants or quantities updates prices instantly.

FAQ

Does it work with product variants?

Yes. Selecting a variant updates the table for that product in real time.

Can I customize the styling?

Absolutely. It inherits your theme styles, but you can override the CSS for custom branding.

Will this slow down my website?

No. The code is lightweight and loads only where needed.

What happens if no pricelists are set?

The table simply doesn’t appear. It gracefully skips products without tiered pricing.

Is it multi-currency compatible?

Yes. Prices automatically display in the user’s active currency and locale format.
