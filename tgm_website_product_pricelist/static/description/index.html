How It Works

This module seamlessly integrates with Odoo's native pricelist functionality. Here's what happens behind the scenes:

  1. You configure your quantity-based pricelists in Odoo (just like normal)
  2. The module automatically detects these pricelists for each product
  3. A beautiful pricing table is displayed on the product page
  4. When customers change variants, the table updates instantly via JavaScript
  5. Customers can see exactly how much they'll save at different quantities
💡 Pro Tip: Use this module to increase average order value by making bulk discounts visible and attractive to customers browsing your products.

Installation & Setup

Getting started is incredibly simple:

  1. Install the Module
    Install "Website Quantity Tiered Pricing Table" from your Apps menu.
  2. Configure Your Pricelists
    Go to Sales → Configuration → Pricelists and set up your quantity-based pricing rules. The module works with your existing pricelist configuration.
  3. Enable on Product Pages
    Edit any product page using the website builder, and check the "Price List" option in the customize menu.
  4. Done!
    Your pricing table will now appear automatically on product pages with configured pricelists.
